# Frontend - WorldTree Dashboard

React/Next.js frontend for the Unified AI Matrix & WorldTree platform.

## Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Features

- WorldTree Dashboard for model management
- Real-time model interaction interface
- Performance monitoring and analytics
- Multi-model conversation interface

## Tech Stack

- React 18+
- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui components
