# SACA Application: Medical Health (V11/V20)

## Context
This module addresses the **"MA-induced Auditory Hallucinations"** challenge, aligning with **SACA Volume 11 (Applications)** and **Volume 20 (Health/Mental)**.

It provides a comparative suitability table for various treatment approaches, specifically focused on the **Australia 2026 Status**.

## Contents

This directory contains polyglot reference implementations of the treatment suitability table:

*   **Python**: `ma_hallucinations.py` (Primary reference for SACA runtime)
*   **Swift**: `ma_hallucinations.swift` (Xcode/macOS compatible)
*   **Rust**: `ma_hallucinations.rs` (High-performance/Safety focused)

## Usage

### Python
Run directly with Python 3:
```bash
python3 ma_hallucinations.py
```

### Swift
Compile and run:
```bash
swift ma_hallucinations.swift
```

### Rust
Compile and run using rustc:
```bash
rustc ma_hallucinations.rs && ./ma_hallucinations
```
