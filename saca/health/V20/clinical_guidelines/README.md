## Star Rating System Source

The star rating system used in the treatment protocols reflects the **Suitability** and **Stability** of the intervention within the Australian 2026 Status framework.

| Stars | Meaning | Criteria |
| :--- | :--- | :--- |
| ★★★★★ | **Excellent** | High stability ("Good"), High involvement, Suitability "Yes". |
| ★★★★☆ | **Strongly Recommended** | Excellent/Moderate stability, Low-High involvement, Suitability "Strongly Recommended". |
| ★☆☆☆☆ | **Restricted / Caution** | Moderate stability, Very Low involvement, Suitability "Allowed (strictly limited)". |
| — | **N/A** | Symptom description (not a treatment). |

### Data Source
The data rows are derived from clinical best practices for psychosis and MA-induced hallucinations.
