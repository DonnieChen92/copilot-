# JCD01: Evidence Vault

Contains signed manifests, integrity artifacts (Merkle roots, PGP signatures), and evidence originals/derivatives.

## Structure

- `evidence/originals/` — Original evidence files
- `evidence/derivatives/` — Processed or derived evidence
- `integrity/manifests-signatures/` — PGP-signed manifests
- `integrity/merkle-roots/` — Merkle root hashes for manifest verification
- `provenance/` — Provenance records
- `exports/` — Export bundles
