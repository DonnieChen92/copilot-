### Key Differences / 關鍵差異 / 关键差异

| Aspect / 面向 | Sync Connector / 同步連接器 | On-demand Connector / 按需連接器 |
|---|---|---|
| **Data Flow / 資料流** | Real-time bidirectional / 即時雙向 | Request-response / 請求-回應 |
| **Background Updates / 背景更新** | Yes — continuous sync / 持續同步 | No — triggered by user / 用戶觸發 |
| **Admin Control / 管理控制** | Full RBAC (Business) | Approval-based (Business) |
| **Data Residency / 資料駐留** | Configurable region / 可配置區域 | Provider-dependent / 依提供者 |
| **Compliance Audit / 合規稽核** | Full logging (Business) | Event-based logging / 事件日誌 |

步驟 5：配置資料共享偏好設定

步驟 6：（Business）管理員審核與批准

## 11. Recommendations / 建議 / 建议

### For SI (Smart Intelligence) Project / 對 SI 專案的建議 / 对 SI 项目的建议

1. **Start with Pro** for individual development and research phase
   以 Pro 開始個人開發和研究階段

2. **Migrate to Business** when team collaboration begins
   團隊協作開始時遷移至 Business

3. **Prioritize sync connectors** (GitHub, Slack, Notion) for development workflow
   優先使用同步連接器用於開發工作流程

4. **Leverage Canva + Claude** cross-platform workflow for SI brand materials
   利用 Canva + Claude 跨平台工作流程製作 SI 品牌材料

5. **Integrate Box** for enterprise document management with compliance logging
   整合 Box 用於企業文件管理與合規日誌

6. **Use HuggingFace connector** for model evaluation and dataset management
   使用 HuggingFace 連接器進行模型評估和資料集管理
