## 2. Domain Decode / 域名解碼 / 域名解码

### The `.ai` Extension / `.ai` 延伸 / `.ai` 扩展

The `.ai` TLD (top-level domain) is:
- **Technically**: Anguilla country code TLD, widely adopted by tech/AI industry
- **Conventionally**: Recognized as the AI industry domain standard
- **In SI philosophy**: Preserved as generic tech identifier, but philosophically
  the "AI" is redefined as **SI** (Smart Intelligence)

保留 `.ai` 作為通用技術識別碼，但在哲學上 "AI" 被重新定義為 **SI**（智慧智能）。

## 5. Voice & Tone / 語調與風格 / 语调与风格

### Writing Principles / 寫作原則 / 写作原则

| Principle / 原則 | Do / 做 | Don't / 不做 |
|---|---|---|
| **Honest / 誠實** | State facts, show actions taken | Empty promises, hype |
| **Trilingual / 三語** | EN + ZH-TW + ZH-CN annotations | Single-language only |
| **Technical / 技術** | Include math foundations, code | Vague hand-waving |
| **Personal / 個人** | Share the human story behind it | Cold, corporate tone |
| **SI-aligned / SI 對齊** | "Smart Intelligence", human-guided | "Artificial", machine-replacing |

### Terminology Guide / 術語指南 / 术语指南

| Instead of / 取代 | Use / 使用 | Reason / 原因 |
|---|---|---|
| Artificial Intelligence | Smart Intelligence (SI) | Human-guided, not man-made |
| AI-powered | SI-driven | Emphasis on human direction |
| AI assistant | SI companion | Partnership, not servitude |
| Machine learning | Pattern learning / 模式學習 | Demystifies the process |
| Neural network | Connection network / 連接網路 | More intuitive |
